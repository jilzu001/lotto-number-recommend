# 로또 번호 추천

플레이: https://jilzu001.github.io/lotto-number-recommend/

입체 버튼을 누르면 1~45 중 중복 없는 6개 번호가 차례로 공개됩니다. 별도 입력과 확정 단계 없이 하루 한 번 추천하며, 한국시간 자정 이후 새 추천을 받을 수 있습니다. 첫 화면의 여섯 칸은 물음표를 유지합니다. 오늘 추천번호는 새로고침 후에도 재추첨 없이 결과창에서 다시 확인합니다. 추천을 다시 누르면 ‘오늘은 이미 추천받았습니다’ 안내가 나타나며 기존 번호 확인으로 이동할 수 있습니다. 실제 금전 지급, 구매, 결제, 당첨번호 조회 기능은 없습니다.

‘최근 추천’ 버튼을 누르면 날짜와 번호가 있는 기록 창이 열립니다. 최신순으로 최근 7개를 이 브라우저에 보관하며, 8번째 추천이 저장되면 가장 오래된 기록을 제외합니다. 기존에 저장된 마지막 추천도 기록에 포함합니다. 같은 날 재시도하거나 결과를 다시 확인해도 기록이 추가되지 않습니다.

## 홈 화면에서 실행

안드로이드 Chrome에서 사이트를 열고 점 세 개 메뉴의 ‘홈 화면에 추가’ 또는 ‘앱 설치’를 선택합니다. 설치한 ‘로또 추천’ 아이콘으로 실행하면 브라우저 주소창 없이 열립니다. 다른 앱 안에서 링크를 열었다면 먼저 Chrome에서 열어 설치합니다. 이전에 만든 단순 바로가기가 있다면 새 설치 아이콘을 사용하세요. 아이폰은 Safari의 공유 메뉴에서 ‘홈 화면에 추가’를 선택합니다. 메뉴 이름은 브라우저에 따라 다를 수 있습니다.

전용 번호 공 아이콘을 제공하며 원본은 icons/icon.svg입니다. 앱 실행 범위는 이 프로젝트 주소 내부로 한정됩니다. 같은 브라우저에서 설치해 실행하면 사이트 저장소를 계속 사용합니다. 기기의 시간·배터리 상태 표시줄은 유지됩니다.

서비스 워커는 오프라인에서 페이지와 저장 기록을 열 수 있도록 캐시합니다. 온라인에서는 페이지를 먼저 네트워크에서 가져오고, 배포 내용이 바뀌면 별도 버전의 캐시로 교체합니다.

## 불규칙 가중치

추천 시 날짜·현재 시각·암호학적 난수로 내부 값을 만듭니다. 번호별 가중치는 0.35~1.85 범위에서 서로 달라지고, 번호 하나가 뽑힐 때마다 남은 모든 번호의 가중치를 새로운 암호학적 난수로 다시 변경합니다. 가중치에 비례해 번호 하나를 뽑고 풀에서 제거하는 작업을 6회 반복합니다. 같은 날짜와 내부 값을 넣어도 새 난수가 매 단계 추가되어 결과는 고정되지 않습니다. 기분 입력이나 실제 감정 추정은 없습니다.

이 방식은 추천 과정의 선택 확률을 변화시키는 연출용 알고리즘입니다. 실제 로또 당첨 확률을 높이거나 미래 당첨번호를 예측하지 않습니다. 번호 범위는 [동행복권 로또 6/45 안내](https://www.dhlottery.co.kr/lt645/intro)의 1~45 형식을 참고했으며, 보너스 번호는 추천하지 않습니다.

## 실행과 배포

`python -m http.server 8766`으로 로컬 실행합니다. GitHub Actions가 `python tools/build_site.py`로 HTML·CSS·JavaScript를 하나의 HTML에 포함하고 GitHub Pages에 배포합니다. 외부 이미지·폰트·라이브러리는 사용하지 않습니다.

하루 제한은 같은 브라우저·사이트의 로컬 저장 기준입니다. 여러 탭의 동시 추천은 Web Locks로 조정합니다. 저장 기능이 차단되거나 Web Locks를 지원하지 않는 브라우저에서는 추천을 저장할 수 없습니다. 브라우저 데이터를 지우거나 다른 기기에서 접속하면 기록이 공유되지 않습니다.

Microsoft Edge 실제 브라우저 엔진으로 모바일 화면 크기와 데스크톱 동작을 검증했습니다. 검증 항목은 VERIFICATION.md에 있습니다.
